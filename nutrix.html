Nutrix Resynced

Comprehensive AI platform for personalized nutrition planning on mobile. Groq-powered chatbot, dynamic nutritional seeding, and real-time dietary tracking.

View on GitHub ↗
Overview

Nutrix Resynced is an end-to-end AI-powered diet planning platform architected with React Native (Expo) for cross-platform mobile and FastAPI for the async backend.

The platform features a Groq-powered conversational chatbot (Llama 3.3 70B) for dietary advice, a dynamic nutritional seeding pipeline integrated with the FatSecret API, and a robust PostgreSQL + Redis backend deployed on Render.

The app delivers personalized meal plans, macronutrient tracking, interactive charts, and a social discovery feed — all wrapped in a polished mobile experience with smooth animations powered by Reanimated and Chart Kit.

Architecture

Key Features
  • Cross-Platform Mobile: React Native (Expo) delivering native-quality experience on both iOS and Android.
  • AI-Powered Chatbot: Groq Llama 3.3 70B integrated for real-time dietary advice and meal recommendations.
  • Dynamic Nutritional Seeding: FatSecret API integration for verified nutritional data and food database.
  • Async Backend: FastAPI with SQLAlchemy async engine and PostgreSQL for high-throughput data operations.
  • Media Processing: Cloudinary integration for OCR capabilities and cloud media storage.
  • Interactive Visualizations: Reanimated and Chart Kit for smooth, animated macronutrient tracking charts.
